# 実験: 音声認識を Workers AI Whisper に置き換える

2026-09-25

## 目的

ブラウザの音声認識（Web Speech API）の認識精度に課題があったため、Cloudflare Workers AI の `@cf/openai/whisper-large-v3-turbo` に置き換えると改善するかを確かめた。

## 結論

**不採用。ブラウザの音声認識のままとする。**

書き起こしの精度と扱いやすさは良好だった。しかし、締め切りから書き起こしが返るまでに 1〜4 秒かかり、実際にプレイして待ち時間が長すぎると判断した。このゲームは「締め切りから即座にキャラが動き出す」ことを面白さの一つにしているため、待ち時間を優先した。

## 試した構成

- ブラウザの `MediaRecorder` で音声入力の 3 秒間だけを録音し、締め切り後に Worker の `/api/transcribe` へ送る。Worker が `env.AI.run()` で Whisper を呼ぶ。
- Whisper の入力は、音声（base64）、`language: "ja"`、短い `initial_prompt`（「右に2マス、下に突き当たりまで、左にまっすぐ、上に分かれ道まで。」）、`vad_filter: true`、`condition_on_previous_text: false`。
- マイクは START 直後の許可確認で開いた `MediaStream` を録音まで使い回した。録音開始時に `getUserMedia` し直すと、開始が遅れて話し始めが欠けるため。
- 比較のため、ブラウザの音声認識を並行して動かし、Whisper が失敗するか 6 秒以内に返らないときはその結果で続行する作りにした。
- `wrangler.jsonc` に `"ai": { "binding": "AI" }` を追加した。

## 結果

### 読み上げ音声での書き起こし（Worker の `/api/transcribe` を直接呼び出し）

macOS の読み上げ（Kyoko）で作った音声を、Chrome の録音形式（webm/opus）と Safari の録音形式（mp4/aac）に変換して送った。時間は Worker 内で `AI.run()` を挟んで計測したもの（ローカル開発から Cloudflare への往復を含む）。

| 正解 | 書き起こし（2 形式とも同じ） | 時間 |
| --- | --- | --- |
| 右に突き当たりまで、下に2マス | 右に突き当たりまで、下に2マス。 | 1.5〜1.9 秒 |
| 右まっすぐ下1マス | 右まっすぐ、下1マス。 | 0.7 秒 |
| 右下右下 | 右下右下。 | 0.9〜1.3 秒 |
| 上に3マス左に1マス | 上に3マス、左に1マス。 | 0.7〜2.1 秒 |
| 左に曲がって分かれ道まで | 左に曲がって分かれ道まで。 | 0.7〜0.9 秒 |
| （3 秒の無音） | （空文字） | 0.5 秒 |

### ブラウザからの通し（録音 → Whisper → Jev → 移動）

ブラウザペインではマイクが使えないため、読み上げ音声を `getUserMedia` の代わりに流し込んで 4 回通した。

- 3 回は正しく書き起こされた（「右まっすぐ下1マス。」）。締め切りから書き起こしが返るまで 1.0〜4.2 秒（1.8 / 1.3 / 1.1 / 4.2 秒）。
- 1 回目だけ、Whisper が `3030: Failed to decode audio file` を返した。同じ条件で繰り返しても再現せず、原因は特定できていない。
- 実際の声でのプレイ（Chrome）でも、待ち時間が長いという感触だった。

## 分かったこと

- **精度・形式**
  - 読み上げ音声では 5 文すべて正確に書き起こせた。数字も「2マス」のような算用数字で返る。
  - 区切りのない発話にも読点を付ける（「右まっすぐ、下1マス。」）。Jev にとって読みやすい。ただし「右下右下」には読点が付かなかった。
  - Chrome（webm/opus）と Safari（mp4/aac）の録音形式を、変換なしで受け付けた。
  - `vad_filter: true` のもとでは、無音で架空の文（「ご視聴ありがとうございました」など）を出すことはなかった。
- **待ち時間**
  - 締め切り後に音声全体を送って一括処理するため、書き起こしが返るまで 1〜4 秒かかり、ばらつきも大きい。ブラウザの音声認識は話している間に認識が進むので、締め切り後の確定は 1 秒未満で済む。
  - 締め切り後の待ちは「考えています…」の時間にそのまま加わり、ゲームのテンポを損なう。
- **運用**
  - Workers AI は、ローカル開発中も Cloudflare のアカウント上で実行され、利用料が発生する。そのため `wrangler login` が必要。
  - 費用は 1 分 $0.0005 程度で、3 秒のプレイ 1 回あたり約 $0.00003 と、問題にならない水準だった。

## 再検討するときの候補

- **話しながら送る方式**：Workers AI の `@cf/deepgram/nova-3` は WebSocket で、話しながら逐次書き起こせる。締め切り後の待ちを短くできる可能性がある。ただし日本語への対応は未確認で、単価は Whisper の約 10 倍（1 分 $0.0052、WebSocket では $0.0092）。
- **ブラウザの音声認識と組み合わせる**：ゲームはブラウザの音声認識で即座に進め、Whisper の書き起こしは記録や評価データの収集にだけ使う。
